## Промпт-дизайн и использование ИИ

При разработке **TONWERK / ЛИНИЯ 425** я использовал ИИ для поиска концепции, проектирования взаимодействия, создания визуальных материалов и реализации музыкального инструмента.

| Инструмент        | Задача                                                               | Уровень |
| ----------------- | -------------------------------------------------------------------- | ------- |
| ChatGPT           | Концепция «номер как мелодия» и механика дискового телефона          | 1       |
| ChatGPT, ImageGen | Визуальное направление, обложка и изображения для лонгрида           | 1–2     |
| ChatGPT           | Звуковая система, сценарий выступления `12·04·61` и промпты           | 2       |
| Codex             | React-код, Tone.js, два голоса, интерактивность и публикация проекта | 3       |

**Примеры запросов**

- **Концепция:** превратить советский дисковый телефон в музыкальный инструмент без традиционной клавиатуры.
- **Интерфейс:** упростить управление по принципу «меньше, но лучше» и использовать кремовый корпус, графит и красный функциональный акцент.
- **Звук:** построить мелодию вокруг телефонного сигнала 425 Гц и объединить голоса LINE и SIGNAL в одну тембровую систему.
- **Разработка:** реализовать дисковый набор нот, управление музыкой через трубку и макроконтрол «Дальность» на React и Tone.js.

**Моя роль**

Я выбрал и развил концепцию, определил метафору связи с прошлым, механику взаимодействия, визуальный язык и сценарий выступления. Я формулировал задачи и ограничения, проверял работу инструмента, оценивал предложенные решения и вносил правки. ИИ помогал быстрее реализовывать, визуализировать и тестировать идеи, но итоговые решения принимал я.

**Вывод**

Не все предложенные решения подходили с первого раза. В процессе работы я научился точнее формулировать запросы, замечать несогласованность между звуком, интерфейсом и концепцией, а затем последовательно упрощать проект до одного цельного музыкального высказывания.
