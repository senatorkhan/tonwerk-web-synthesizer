# TONWERK / NACHKLANG

**NACHKLANG** — авторский браузерный инструмент о следе, который звук оставляет после себя. Это не классический синтезатор с открытыми генераторами, фильтрами и эффектами. Пользователь видит только четыре действия: сыграть звук сейчас, сохранить его след, запустить память и изменить расстояние между настоящим и воспоминанием.

Проект создан на React и Tone.js как небольшое музыкальное высказывание, которое можно освоить без опыта и исполнить за 1–3 минуты.

## Идея: NOW / TRACE / DISTANCE

У инструмента три смысловых слоя:

- **NOW** — звук, который возникает от нажатия прямо сейчас;
- **TRACE** — сохранённый отпечаток сыгранной фразы;
- **DISTANCE** — степень удаления следа от его источника.

Пока музыкант играет, настоящее остаётся ясным и близким. Записанные события возвращаются как второй, более мягкий и пространственный голос. Чем больше **Distance**, тем сильнее TRACE отделяется от NOW: становится темнее, шире и менее определённым.

Главная мысль проекта: **звук заканчивается, но его влияние остаётся**.

## Почему интерфейс такой простой

Подход опирается на принцип Дитера Рамса «меньше, но лучше». На панели нет параметров, которые требуют знания синтеза. Каждая видимая деталь отвечает за отдельное музыкальное действие, а вся техническая сложность остаётся внутри:

- форма следует функции;
- красный цвет обозначает активное действие или записанный след, а не служит украшением;
- восемь ячеек показывают реальное состояние памяти;
- управление можно понять без инструкции и выполнить одной рукой;
- результат выразителен при небольшом количестве решений.

Кастомная особенность NACHKLANG — это не новый набор тембров, а **инструментальная память**. Пользователь не программирует музыку заранее: интерфейс запоминает его собственную игру и превращает её в материал композиции.

## Управление

- **A S D F G H J K** — восемь безопасных нот NOW из F minor pentatonic;
- **Capture** — начать запись следующих восьми нажатий;
- **Play** — запустить циклическое воспроизведение TRACE;
- **Stop** — остановить цикл, не стирая сохранённую фразу;
- **Distance** — приблизить след к NOW или отправить его глубже в пространство;
- **Clear** — очистить память и вернуть инструмент к тишине.

```text
Клавиша:  A   S    D    F   G    H   J    K
Нота:     F4  Ab4  Bb4  C5  Eb5  F5  Ab5  Bb5
```

## Два скрытых голоса

Внутри сохраняется требуемая двухголосная архитектура, но она больше не демонстрируется как техническая схема на лицевой панели.

### Voice 1 — NOW

Прямой полифонический голос для живой игры. Он звучит ближе, яснее и быстрее реагирует на нажатие.

```text
PolySynth → Filter → Chorus → Feedback Delay → Present Gain → Panner → Master → Limiter
```

### Voice 2 — TRACE

Отдельный голос памяти. Он воспроизводит сохранённые ноты и получает более мягкую атаку, фильтрацию, панорамное движение и пространственный хвост.

```text
MonoSynth → Filter → Distortion → Reverb → Memory Gain → Panner → Master → Limiter
```

**Distance** управляет несколькими скрытыми параметрами одновременно: задержкой, фильтром, глубиной пространства, стереопозицией и отношением громкостей NOW/TRACE. Один жест меняет всю сцену согласованно.

## 8-step memory

Восемь ячеек — не традиционный драм-секвенсор. Это видимая кратковременная память инструмента.

1. Нажмите **Capture**.
2. Сыграйте до восьми нот.
3. Каждое нажатие занимает следующую ячейку.
4. Нажмите **Play**, и сохранённый жест начнёт повторяться как TRACE.
5. Продолжайте играть поверх цикла голосом NOW.
6. Нажмите **Clear**, чтобы след исчез.

Если остановить запись кнопкой **Hold** раньше восьмого нажатия, оставшиеся ячейки станут паузами в конце цикла. Тишина остаётся частью фразы, но каждое записанное нажатие всегда занимает следующую ячейку.

## СЛЕД / TRACE — сценарий выступления на 1:40–2:00

Это оригинальная простая композиция для демонстрационного видео. Темп можно чувствовать свободно; важнее спокойные паузы и постепенное изменение Distance.

### Основная восьминотная фраза

```text
Клавиши:  A   S    F   D    G    F   S    A
Ноты:     F4  Ab4  C5  Bb4  Eb5  C5  Ab4  F4
```

Играть ровно, примерно по одной ноте в секунду. Ошибка не ломает выступление: именно сыгранная версия становится уникальным следом.

### Драматургия

- **0:00–0:15 — NOW.** Нажмите **Clear**. Distance около 10–15%. Медленно сыграйте `A — S — F — G`, оставляя воздух между нотами.
- **0:15–0:30 — CAPTURE.** Нажмите **Capture** и сыграйте восемь нот: `A S F D G F S A`. Ячейки памяти последовательно заполняются.
- **0:30–0:55 — TRACE.** Нажмите **Play**. Дайте циклу прозвучать один раз без вмешательства, затем поверх него редко добавляйте NOW: `A`, пауза, `F`, пауза, `G`.
- **0:55–1:20 — DISTANCE.** Одним медленным движением поднимите Distance примерно с 20% до 70%. На фоне удаления следа сыграйте ответ `K G F — D S A` два раза; во второй раз оставляйте больше пауз.
- **1:20–1:40 — ОТСУТСТВИЕ.** Больше не играйте. Поднимите Distance до 85–90% и дайте TRACE существовать самостоятельно.
- **1:40–1:55 — CLEAR.** Нажмите **Clear** во время цикла. После внезапной тишины один раз нажмите и удержите `A`, затем отпустите. Это единственный звук, который не станет воспоминанием.

Весь перформанс строится на четырёх понятных действиях: **Capture → Play → Distance → Clear**. Поэтому исполнителю не требуется виртуозность, а зритель может услышать и увидеть идею проекта.

## Запуск проекта

Требуется Node.js **22.13.0 или новее**.

```bash
npm install
npm run dev
```

Откройте адрес, показанный в терминале, затем нажмите клавишу инструмента или **Play**.

Проверка production-сборки:

```bash
npm run build
```
